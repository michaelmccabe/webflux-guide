# Guide to Payment Entity

The `Payment` class represents the persistent domain model for a payment in the database.

## Class Definition
Located at: [Payment.java](file:///Users/michaelmccabe/local-code/java/reactive-guide/src/main/java/com/example/reactiveguide/domain/Payment.java)

```java
package com.example.reactiveguide.domain;

import lombok.AllArgsConstructor;
import lombok.Builder;
import lombok.Data;
import lombok.NoArgsConstructor;
import org.springframework.data.annotation.Id;
import org.springframework.data.relational.core.mapping.Table;

import java.math.BigDecimal;
import java.time.Instant;

@Data
@NoArgsConstructor
@AllArgsConstructor
@Builder
@Table("payments")
public class Payment {
    @Id
    private Long id;
    private BigDecimal amount;
    private String currency;
    private PaymentStatus status;
    private Instant paymentDate;
    private Instant createdAt;
    private Instant updatedAt;
}
```

## Description and Purpose
- **Database Mapping**: It maps to the database table `payments` using the `@Table` annotation from Spring Data Relational.
- **Primary Key**: The `id` field is annotated with `@Id` to identify it as the primary key. Since it is mapped to a `BIGSERIAL` database column, the ID is automatically generated by the database when a new entity is inserted (i.e. when `id` is null).
- **Lombok Annotations**:
  - `@Data`: Automatically generates boilerplate methods like getters, setters, `toString()`, `equals()`, and `hashCode()`.
  - `@Builder`: Provides a builder pattern for clean object construction.
  - `@NoArgsConstructor` & `@AllArgsConstructor`: Generates required constructors for runtime instantiation and deserialization.

## Usage Example
```java
// Constructing a new Payment entity
Payment payment = Payment.builder()
        .amount(new BigDecimal("100.00"))
        .currency("USD")
        .status(PaymentStatus.PENDING)
        .paymentDate(Instant.now())
        .build();
```
