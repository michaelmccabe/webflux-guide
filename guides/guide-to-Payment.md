# Guide to Payment Entity

The `Payment` record represents the persistent domain model for a payment in the database. As a Java record, it is implicitly immutable, which aligns with reactive programming best practices to prevent state side-effects.

## Record Definition
Located at: [Payment.java](file:///Users/michaelmccabe/local-code/java/reactive-guide/src/main/java/com/example/reactiveguide/domain/Payment.java)

```java
package com.example.reactiveguide.domain;

import lombok.Builder;
import org.springframework.data.annotation.Id;
import org.springframework.data.relational.core.mapping.Table;

import java.math.BigDecimal;
import java.time.Instant;

@Builder(toBuilder = true)
@Table("payments")
public record Payment(
    @Id Long id,
    BigDecimal amount,
    String currency,
    PaymentStatus status,
    Instant paymentDate,
    Instant createdAt,
    Instant updatedAt
) {}
```

## Description and Purpose
- **Database Mapping**: It maps to the database table `payments` using the `@Table` annotation from Spring Data Relational.
- **Primary Key**: The `id` field is annotated with `@Id` to identify it as the primary key. Since it is mapped to a `BIGSERIAL` database column, the ID is automatically generated by the database when a new entity is inserted (i.e. when `id` is null).
- **Immutability**: All fields are `private final` by design. This avoids concurrency issues when processing streams across event loops in Project Reactor.
- **Lombok `@Builder`**:
  - Annotated with `@Builder(toBuilder = true)` to provide a builder pattern for clean object construction and to allow creating updated copies of the record (e.g. `payment.toBuilder().status(...).build()`).
- **Accessors**: Automatically exposes getter-like accessor methods using the field name (e.g., `payment.amount()` instead of `payment.getAmount()`).

## Usage Example
```java
// Constructing a new Payment record
Payment payment = Payment.builder()
        .amount(new BigDecimal("100.00"))
        .currency("USD")
        .status(PaymentStatus.PENDING)
        .paymentDate(Instant.now())
        .build();

// Creating an updated copy of the record
Payment completedPayment = payment.toBuilder()
        .status(PaymentStatus.COMPLETED)
        .updatedAt(Instant.now())
        .build();
```
